# Medieval-Market (VR) 🏰🛡️

A stylized Medieval Market VR experience built in Unity (URP) using Meta XR Interaction SDK. Explore themed stands (weapons, armor, bakery, butcher, produce, fish), interact with objects using Ray Grab / Distance Grab, and complete mini interactions like collecting coins, opening info cards, and customizing gear.

✨ Features

VR Interactions (Meta XR Interaction SDK)

Ray Grab + Distance Grab

Poke interactions for UI and selection orbs

World-Space UI

Info cards, welcome signage, and contextual prompts

Smooth UI reveal (fade/scale) and auto-hide after a delay

Mini Gameplay

Coin collection: drop 3 coins into a pouch → sound + feedback + “Congrats” card

Armor customization: touch color orbs to swap armor materials

URP Lighting + Stylized Environment

Low-poly medieval market scene layout with themed areas

🧰 Tech Stack

Engine: Unity (URP)

VR: Meta XR Interaction SDK

UI: World-space Canvas + TextMeshPro

Audio: Unity AudioSource + OneShot SFX

Scripting: C# (interaction logic, UI, collectibles)
